핵심 수정
1. 체크리스트 선택 시 '선택 업무 등록' 폼이 사라지던 HTML 구조 오류 수정
2. 체크리스트 선택 → 업무구분/업무명 자동입력 → 등록폼으로 부드럽게 이동
3. 점포등록 → 업무등록 → 업무처리현황 → 출납 저장/조회 순서 유지
4. 업무등록 화면을 STEP 1~3 구조로 재디자인
5. 상단 히어로 이미지, 카드형 UI, 반응형 모바일 디자인 적용

주의
- Apps Script Code는 이번 ZIP에서 변경하지 않습니다.
- 기존 배포된 Apps Script URL은 store-opening.js에 그대로 유지했습니다.
